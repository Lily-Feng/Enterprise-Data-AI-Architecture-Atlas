01

What we're building

The same target across all three sessions — only how much of it gets built live changes.

GitTrend
An AI agent grounded in 107 million real GitHub events (GH Archive, loaded from public S3), answering plain-English questions about what developers are actually building. A human never writes SQL — CoCo writes every statement, in a terminal, directed by prompts.
GITHUB_EVENTStable
107M rows copied in from S3 — the raw, read-only source of truth.
V_TRENDING_AI_REPOSview
CoCo reads the raw schema, infers what "starred" means, and builds this after being asked to find trending AI/ML repos.
AI_COMPLETEfunction
Wraps the view's rows in an LLM call so results come back as a written summary, not a table.
GITHUB_REPO_SEARCHsearch service
A Cortex Search semantic index over the view — the agent's retrieval tool.
GITTRENDCortex Agent
Search + chart tool + system prompt. This is what you actually talk to, and it remembers the conversation across turns.
GITTREND_MCPMCP Server · optional
Exposes GITTREND to Claude Desktop, Cursor, or any MCP client outside Snowflake, over OAuth.
Cost governanceoptional
Resource monitors, budgets, and per-user quotas so the finished agent can't spend without a ceiling.

02

What a human needs to set up

CoCo writes the SQL. It doesn't do these five things for you — they happen before the first prompt.

1

A Snowflake trial account, from the event-specific link

Not a generic trial signup — the AI features this workshop needs only activate inside a short UTC window tied to a specific event link (e.g. Aug 18–23 for an Aug 20 session).

Signing up too early is the single most common attendee failure.
2

The CoCo CLI, installed and verified

One script per platform, then a version check.

# macOS / Linux / WSL
curl -LsS https://ai.snowflake.com/static/cc-scripts/install.sh | sh

# Windows (PowerShell)
irm https://ai.snowflake.com/static/cc-scripts/install.ps1 | iex

# verify
cortex --version
3

A project folder with an AGENTS.md

Plain text — your account identifier, role, warehouse, database/schema, and what CoCo must never touch. CoCo loads it automatically from whatever folder you launch it in. This is the one piece of the pattern worth taking to any other dataset.

Account: <your-snowflake-account-identifier>
Role: ACCOUNTADMIN
Warehouse: WORKSHOP_WH
Database: GITTREND_DB
Do NOT modify: production tables, RBAC roles, cost-sensitive resources.
4

A connection from CoCo to Snowflake

First launch opens a setup wizard. Fastest path is "Sign in with browser" (pulls your existing Snowsight session, no typed credentials) — or reuse a connection CoCo shares with the Snowflake CLI, from ~/.snowflake/connections.toml.

5

ACCOUNTADMIN — only if you're doing cost governance

Reading ACCOUNT_USAGE cost views and setting budgets or per-user quotas requires it. Not needed for the core agent build.

03

What Cortex / CoCo can actually do

The building blocks a prompt can reach for, grouped by what they're for.

Write and understand data
CoCo CLI

An agentic terminal tool that writes and runs SQL for you, reasons about your schema, and reads AGENTS.md for context every session.

Schema inference

Handed a raw table, CoCo infers meaning that isn't written anywhere in the schema — e.g. that a WatchEvent means a repo was starred.

AI_COMPLETE

An LLM call usable directly inside SQL — turns query results into a written summary. Successor to the deprecated CORTEX.COMPLETE.

Cortex Search

A managed semantic search index over a table or view column — the retrieval tool an agent searches against.

Orchestrate and expose an agent
Cortex Agents

Orchestrates tools — search, chart, SQL, semantic-view analyst — behind a system prompt. auto model selection means Snowflake upgrades the model under it without you touching the config. Holds memory across turns via Agent Threads.

data_to_chart

A tool an agent can call on its own judgement to render a visualization inline, instead of a table of numbers.

MCP Server

A DDL object exposing an agent, search service, or SQL execution to any MCP client — Claude Desktop, Cursor, VS Code — over OAuth. No separate infrastructure to stand up.

Cortex Analyst / Semantic Views

A governed, structured alternative to search — the agent generates SQL directly from a business-defined semantic model.

Extend and govern
Agent Skills

SKILL.md files uploaded to a stage that teach an agent new behavior without redeploying it.

MCP Connectors (outbound)

The reverse of an MCP Server — an agent calling out to Jira, Salesforce, or an internal API to take action, not just answer.

Cost visibility

CoCo's built-in Cost Intelligence skill plus four ACCOUNT_USAGE views (5 min – 3 hr latency) show credits by service, user, model, and agent.

Cost controls

Resource Monitors cap warehouse compute; Budgets cap AI credit spend account-wide; Per User Quotas cap it person-by-person, enforced within minutes.

04

Sample prompts, from the three live events

Same agent, same dataset, three rooms — each one pushed a different layer live instead of leaving it as take-home.

ODSC AI × Snowflake — San Francisco
Aug 6, 2026 · Mindspace Coworking, SF · ~100 attendees · guide v1
v1 · core build
Large, mixed-level room, 60 minutes. The 5-step core build lands live; MCP goes home as a stretch exercise.
> explore the schema
I have a table called GITTREND_DB.PUBLIC.GITHUB_EVENTS loaded from the GitHub Archive. Explore it: describe the key columns, explain what types of GitHub events are tracked. Tell me which columns would be most useful for finding trending AI and ML repositories by star activity.
> build the trending view
Create a view called V_TRENDING_AI_REPOS that finds repos that gained the most stars in the last 30 days. Where the repo name suggests AI, ML, LLM, GPT, agent, MCP, or open source. Only include repos with 10 or more stars gained. Show the top 20 by stars gained, descending.
> wrap it in AI_COMPLETE
Wrap the results in a call to AI_COMPLETE so it returns a natural language summary: name the top 3 trending repos and why they're gaining momentum, note any patterns across language or topic, 3–4 sentences max. Use the 'claude-sonnet-4-6' model.
$ asked of the finished agent
"What's the fastest-growing AI project in the last 30 days?"
TechEquity AI Forum — Level 2
Jul 28, 2026 · Snowflake SVAI Hub, Menlo Park · guide v2
v2 · MCP live
Smaller, technical room, 75 minutes. Steps 3–5 compress into one rapid block, freeing time to run the MCP + OAuth handshake live instead of take-home.
> create the MCP server
Create an MCP Server called GITTREND_MCP that exposes the GITTREND agent as a tool. Tool name: "gittrend". Tool type: CORTEX_AGENT_RUN. Description: "GitHub trend analyst with 30 days of real star activity data. Ask it about trending repos, emerging AI/ML projects, and developer momentum."
> set up OAuth so a client can connect
CREATE OR REPLACE SECURITY INTEGRATION GITTREND_MCP_OAUTH TYPE = OAUTH OAUTH_CLIENT = CUSTOM OAUTH_CLIENT_TYPE = 'CONFIDENTIAL' OAUTH_REDIRECT_URI = 'https://claude.ai/api/mcp/auth_callback';
$ asked from Claude Desktop / Cursor, via MCP
"Compare the top 5 repos — what do they have in common?" "Are there any surprise breakouts — repos nobody knows yet but are gaining fast?"
TechEquity AI Infrastructure Forum
Aug 20, 2026 · Snowflake SVAI Hub, Menlo Park · 612 registered · guide v3
v3 · cost intelligence
Concurrent with keynotes, running alongside a security keynote on agent authorization. Picks up the v2 agent and asks the infrastructure question: what does it cost, and what stops it running away?
> see what it's costing
Show me a breakdown of AI credit usage in my Snowflake account over the last 7 days. Start with a high-level summary using METERING_HISTORY — total credits by service type. Then show detail from CORTEX_AI_FUNCTIONS_USAGE_HISTORY grouped by function and model, and CORTEX_AGENT_USAGE_HISTORY grouped by agent and user.
> put a ceiling on it
Create a resource monitor called WORKSHOP_AI_MONITOR. Apply it to WORKSHOP_WH. Credit quota: 10 credits. Notify me at 80% usage, suspend the warehouse at 100%. Set up a per-user AI spending quota. Monthly limit: 20 credits. Daily limit: 5. Enable block enforcement.
> ask CoCo to optimize its own agent
Use the Cost Intelligence skill. Show me my AI function spending this week, grouped by function, model, and day. Then give me a specific recommendation to reduce the cost of the GITTREND agent — I want to keep it under 2 AI credits per day.
