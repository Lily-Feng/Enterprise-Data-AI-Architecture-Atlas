# Notes

Notes are the inbox of the knowledge base: small, dated, and honest about uncertainty. Capture the question, source, useful insight, interpretation, and connections. Promote repeated insights into concepts, capabilities, or product pages.

Start from the [learning-note template](../templates/learning-note.md). A note is allowed to be incomplete; it should not be uncited or ambiguous about what is inferred.
